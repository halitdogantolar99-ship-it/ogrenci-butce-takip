# Öğrenci Bütçe ve Harcama Takipçisi

Öğrencilerin aylık bütçelerini planlamalarını, günlük harcamalarını kategorilere göre takip etmelerini ve kalan bakiyelerini anlık olarak görmelerini sağlayan web tabanlı kişisel finans takip uygulaması.

## Canlı Uygulama ve Proje Yönetimi

* **Canlı Web Uygulaması (GitHub Pages):** https://halitdogantolar99-ship-it.github.io/ogrenci-butce-takip/
* **Kanban Proje Panosu (GitHub Projects):** https://github.com/users/halitdogantolar99-ship-it/projects/1

## Tamamlanan Özellikler

* **Harcama Ekleme ve Listeleme (#4):** Açıklama, kategori ve tutar bilgisiyle yeni harcama kaydı oluşturma ve tabloda listeleme.
* **Toplam Bütçe ve Kalan Bakiye Hesaplama (#7):** Aylık hedef bütçe belirleme, toplam harcamayı otomatik hesaplama ve kalan bakiyeyi dinamik renk uyarısıyla gösterme.
* **Harcama Kaydı Silme (#8):** Hatalı veya iptal edilen harcamaları tek tıkla listeden kaldırma ve bakiyeyi anında güncelleme.
* **Kategoriye Göre Filtreleme (#9):** Harcamaları *Yemek, Ulaşım, Kırtasiye, Diğer* kategorilerine göre filtreleme.
* **Tarayıcı Hafızasında Kalıcı Saklama (#10):** `localStorage` altyapısı ile sayfa yenilense veya tarayıcı kapatılsa bile bütçe ve harcama verilerini koruma.

## Kullanılan Teknolojiler

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Versiyon Kontrol & Proje Yönetimi:** GitHub, GitHub Issues, GitHub Projects (Kanban), GitHub Pages
